# Homebrew tap for IWC

```sh
brew install hussian007/iwc/iwc
```

This installs the official [IWC Framework CLI](https://github.com/Hussian007/iwc) release for macOS (Apple silicon, Intel) and Linux (x86_64, arm64). Upgrade with `brew upgrade iwc`. To uninstall, run `brew uninstall iwc && brew untap hussian007/iwc`.

`Formula/iwc.rb` is generated and updated by each release. Please don't edit it by hand.
